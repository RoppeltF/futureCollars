Create a simple consol e -based Python application to manage a library of books. The program should allow the user to:

1.Display all books along with their availability status (available or borrowed).

2.Add new books by entering the title and author.

3.Borrow a book by selecting its number from the list.

4.Return a previously borrowed book.

5.Save the list of books to a file upon exiting the program and load the list from the file when the program starts.

Each book should have a title, an author, and an availability status. The data should be saved in a text file in the following format:
titl e |autho r |availability
where availability is a boolean value: True or False.
